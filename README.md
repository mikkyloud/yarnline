# Yarnline

A web app that translates text between languages, including Igbo, Yoruba, Hausa, and English.

**Live demo:** [yarnline.vercel.app](https://yarnline.vercel.app)

## About
Yarnline helps people translate spoken or typed text between Nigerian, African, and world languages. It uses the Anthropic Claude API to handle the translations.

## Features
- Translate text between 59 languages, including 17 Nigerian languages such as Yoruba, Igbo, Hausa, and Nigerian Pidgin
- Voice input using the browser's speech recognition
- Listen to translations with text-to-speech playback
- Swap languages in one tap
- Download translations as .txt, Word, or PDF
- Search and social-sharing metadata

## Built With
- HTML, CSS, JavaScript
- Anthropic Claude API
- Web Speech API, jsPDF
- Deployed on Vercel

## Run Locally
```bash
git clone https://github.com/mikkyloud/yarnline.git
cd yarnline
```
Open `index.html` in your browser. Translation needs an Anthropic API key, so use the live demo to try the full app.
